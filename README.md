# portfolio

Personal portfolio site for Zsolt Bencze. Plain HTML/CSS, no build step.

Live: https://zbencz3.github.io/portfolio/

## Updating project links

Search `index.html` for `REPLACE_` and replace each with a real URL when ready:

- `REPLACE_BZAP_SITE` &mdash; Bzap marketing site
- `REPLACE_KOUNT_APPSTORE` &mdash; Kount App Store URL
- `REPLACE_PARKING_LINK` &mdash; Parking App Store or website
- `REPLACE_SOLOFAMILY_SITE` &mdash; SoloFamily marketing site

Until replaced, those links render as muted "(soon)" labels and don't navigate.

## Deploy

Push to `main`. GitHub Pages serves from the root.
